# Sorting algorithms & Big O

This project implements common sorting algorithms in C:

- **Bubble sort**
- **Insertion sort**
- **Selection sort**
- **Quick sort**

Each algorithm includes:
- Printing the array or list after every swap
- A time complexity analysis (Big O files)

## Files
| File | Description |
|------|--------------|
| sort.h | Header file containing all prototypes |
| 0-bubble_sort.c | Task 0: Bubble sort algorithm |
| 0-O | Big O complexity file |
